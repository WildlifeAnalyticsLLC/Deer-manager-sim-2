Deer Manager Sim 2 v1.0

Based on the uploaded Deer Manager Sim v11.5. Original simulation systems remain in place. Hunting now defaults to a retro first-person pseudo-3D projection with turn/walk/binocular/spot controls; overhead view remains available.

To install: host the contents of this folder on an HTTPS website (e.g., GitHub Pages), then open on Android Chrome and choose Add to Home Screen. Service workers/offline mode require HTTPS. Do not open index.html as a file for full PWA features.

Saves use a separate localStorage key from Deer Manager Sim v11.5. Do not assume old save imports are compatible without testing.

The 3D renderer is a prototype pseudo-3D view of existing field deer, not a fully modeled 3D engine. Existing encounter/harvest rules remain in effect.
